# Jak přežít zkouškové

Krátká příručka pro chvíli, kdy je materiálů moc a času nějak málo. Základní plán je ~~naučit se všechno poslední večer~~ rozdělit si práci na menší části.

![Sešit, hrnek kávy a tužka připravené na učení](images/uceni.svg)

*Ideální stav stolu. Ve skutečnosti tam většinou leží ještě tři další sešity.*

## Než začnu

Nejhorší je půl hodiny vybírat, z čeho se vlastně učit. Proto je dobré dát si nejdřív dohromady **okruhy ke zkoušce** a poznámky.

- Najít termín a zkontrolovat, co bude v testu.
- Rozdělit témata na ta, která už trochu umím, a zbytek.
- Dát mobil mimo dosah. Nestačí ho jen otočit displejem dolů.
- Připravit si vodu a něco malého k jídlu.

### Co si dnes odškrtnu

- [x] Stáhnout materiály.
- [x] Vypsat si témata na papír.
- [ ] Projít první dvě kapitoly.
- [ ] Vyzkoušet si otázky bez poznámek.

## Jak se do toho pustit

### Jeden blok učení

Na začátek stačí **25 minut soustředění**, potom krátká pauza. Když se zaseknu u jednoho příkladu, označím si ho a vrátím se k němu později. *Jinak se dá nad jednou stránkou strávit celý večer.*

Na hlídání času se hodí [Pomofocus](https://pomofocus.io/). Když v poznámkách chybí vysvětlení, dá se zkusit [Khan Academy](https://cs.khanacademy.org/).

### Co má smysl zkusit

| Způsob učení | Výhoda | Nevýhoda |
| --- | --- | --- |
| Čtení poznámek | Rychlý přehled látky | Snadno si namluvím, že už to umím |
| Otázky nanečisto | Ukážou, kde mám mezery | Ze začátku to dost drhne |
| Vysvětlení spolužákovi | Musím se vyjádřit vlastními slovy | Musíme si najít společný čas |

## Malá pomůcka v Pythonu

Když nevím, čím začít, můžu si téma náhodně vybrat. Seznam si upravím podle předmětu.

```python
import random

temata = ["proměnné", "podmínky", "cykly", "funkce"]
tema = random.choice(temata)

print(f"Teď si zopakuju: {tema}")
print("Dokážu to vysvětlit bez koukání do sešitu?")
```

## Večer před zkouškou

Projít si hlavní body, nachystat věci na ráno a zkontrolovat budík. **Nemusím mít v hlavě každou větu ze skript.** Hlavně ať ráno nehledám učebnu pět minut po začátku.
